# Contribuir

Este repositorio es público para evaluación técnica, pero no funciona como un
proyecto de código abierto. La licencia no concede permiso para reutilizar,
modificar o redistribuir el código sin autorización escrita.

## Propuestas y errores

Las incidencias reproducibles y las propuestas de mejora pueden comunicarse en
GitHub Issues sin incluir datos personales, credenciales, información interna o
capturas de terceros. Una propuesta debe indicar:

- el problema observado;
- el comportamiento esperado;
- los pasos mínimos para reproducirlo;
- el navegador, dispositivo o entorno relevante.

La apertura de un issue no implica aceptación, plazo de resolución ni cesión de
derechos sobre el proyecto.

## Seguridad

Las vulnerabilidades no deben publicarse en un issue. Sigue el procedimiento de
[SECURITY.md](SECURITY.md) y utiliza el canal privado indicado allí.

## Cambios de código

No se aceptan pull requests externos sin coordinación previa. Para plantear una
colaboración profesional, consulta [SUPPORT.md](SUPPORT.md).
