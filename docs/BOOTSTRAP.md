# Plataforma de gestión

Demostración SaaS modular con identidad neutral y datos exclusivamente
ficticios.

El proyecto muestra una arquitectura full-stack, procesos, permisos,
automatización y experiencia de producto sin reproducir código, datos,
pantallas ni estructuras internas de ninguna organización.

## Estado

La versión estable actual es `v1.3.2` y está publicada en
<https://plataformagestion.app>. El repositorio es público para su evaluación,
pero el código y los recursos originales mantienen una licencia propietaria.
